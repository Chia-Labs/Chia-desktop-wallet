## Install

<details open>
<summary><img src="https://img.shields.io/badge/OS-Windows-3EAC5C?style=flat-square&labelColor=424F6D&logo=data%3Aimage%2Fsvg%2Bxml%3Bbase64%2CPHN2ZyB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciIHZpZXdCb3g9IjAgMCAyNCAyNCI%2BPHBhdGggZmlsbD0iI0ZGRkZGRiIgZD0iTTMgNS42bDcuNC0xLjF2Ni45SDNWNS42em04LjUtMS4yTDIxIDN2OC40aC05LjVWNC40ek0zIDEyLjZoNy40djYuOUwzIDE4LjR2LTUuOHptOC41IDBIMjFWMjFsLTkuNS0xLjR2LTd6Ii8%2BPC9zdmc%2B&logoColor=FFFFFF" alt="Windows" height="22"></summary>

1. Download `chia-wallet-setup-2.7.5.exe` from the release assets.
2. Run `certutil -hashfile chia-wallet-setup-2.7.5.exe sha256` in Command Prompt and compare the output with the SHA-256 table above.
3. Double-click the installer and accept the elevation prompt, because it writes to protected locations.
4. Open Chia Wallet from the Start menu and choose wallet mode or farming mode.

Windows 10 (1909) or later, 64-bit. No extra runtime to install first.

</details>

<details>
<summary><img src="https://img.shields.io/badge/OS-macOS-3EAC5C?style=flat-square&labelColor=424F6D&logo=apple&logoColor=FFFFFF" alt="macOS" height="22"></summary>

1. Download `Chia-2.7.5-arm64.dmg` for Apple silicon, or `Chia-2.7.5.dmg` for an Intel Mac.
2. Open the disk image and drag Chia Wallet into Applications.
3. Verify the file first with `shasum -a 256 Chia-2.7.5-arm64.dmg` and compare it with the table above.
4. Launch the app from Applications. macOS may ask for confirmation because the build was downloaded from the internet.

macOS 12 or later, on Apple silicon or Intel.

</details>

<details>
<summary><img src="https://img.shields.io/badge/OS-Linux-3EAC5C?style=flat-square&labelColor=424F6D&logo=linux&logoColor=FFFFFF" alt="Linux" height="22"></summary>

1. Download `chia-blockchain_2.7.5_amd64.deb` for x64, `chia-blockchain_2.7.5_arm64.deb` for ARM64, or the `.rpm` for CentOS and Red Hat.
2. Check the file: `sha256sum chia-blockchain_2.7.5_amd64.deb` against the value above.
3. Install it with `sudo apt install ./chia-blockchain_2.7.5_amd64.deb`, or `sudo rpm -i chia-blockchain-2.7.5-1.x86_64.rpm`.
4. Start Chia Wallet from your application menu, or run the daemon and use the wallet RPC on a headless machine.

x64, Ubuntu 20.04 or later, or equivalent.

</details>

## Features

- Send and receive XCH and CAT tokens from one account.
- Create offers with a 7-day default expiry, and cancel them from the same list.
- Keep NFT and DID wallets beside the XCH balance, in the same key.
- Run wallet mode for a light client, or farming mode to run a full node and farm.
- Hold several keys in one client and identify each one by its fingerprint.
- Verify every installer against the SHA-256 value published on the release page.

---

## Wallet mode and farming mode

Wallet mode syncs the wallet through peers and keeps almost nothing on disk. Farming mode runs a full node and enables farming, which is the only reason to carry the larger data directory. The choice is made on first start and can be changed later from the settings menu without reinstalling.

---

## Where your data lives

The wallet keeps its data in the Chia directory inside your user profile, including the wallet database and the configuration the client reads at start. The 24-word phrase is not stored there: the key lives in the operating system keychain, encrypted. A copy of the data directory restores convenience, never access - the phrase is the backup.
